# 自媒搭子 · UI 重构方案（v0.1）

> 对象：Easel 上游前端（React 19 + Vite，约 9400 行，17 个页面组件），已复制到 `frontend/`。
> 基于 2026-09-29 逐页走查。

## 1. 现状问题（面向小白用户）

| # | 问题 | 例子 |
|---|---|---|
| 1 | **按"系统功能"命名，而不是按"我要做什么"** | 技能库、画像、网关、通用模式；技能卡片直接显示 `skill-algorithm-updates` 这类内部 ID |
| 2 | **两个起点，不知道从哪开始** | 「工作台」和「对话」都像首页 |
| 3 | **重要页面藏起来了** | 热点、选题、日历、发布、拆爆款只能从首页的一排小按钮进，侧边栏里找不到 |
| 4 | **新用户看到一屏的 0** | 待做选题 0、待发排期 0、内容项目 0、已登录账号 0/7，没有引导下一步做什么 |
| 5 | **技术细节暴露给用户** | 设置里有六个模型通道的 Key / Base URL；底部显示"网关已连接"、`subnav-1` |
| 6 | **视觉是通用 SaaS 模板** | 浅灰背景 + 白卡片 + 细边框，和 logo 的暖橙、圆润、可爱没有关系，去掉 logo 认不出是哪个产品 |
| 7 | **依赖 Google Fonts**（已修复） | 国内访问不到，会导致白屏等待 |

## 2. 信息架构（三个视觉方向共用）

侧边栏从"功能列表"改成**按创作流程排列的 6 个动词**：

| 新导航 | 做什么 | 合并了原来的 |
|---|---|---|
| **首页** | 一句话开始 + 搭子挑好的今日选题 + 进行中的任务 + 本周发布 | 工作台 + 对话起始页 |
| **找灵感** | 热点雷达、选题库、拆解爆款（三个标签页） | 热点、选题、拆爆款（原来都藏着） |
| **创作** | 左边对话，右边**作品实时预览**（卡片、视频、文章边生成边看）；顶部是常用模板；「全部能力」按场景分组，用中文名，不显示技能 ID | 对话 + 技能库 |
| **我的作品** | 作品墙（缩略图），按平台和状态（草稿 / 待发 / 已发）筛选 | 内容库 |
| **发布** | 平台账号绑定状态、发布队列、内容日历 | 账号 + 发布中心 + 日历 |
| **我的定位** | 账号人设（原画像），首次使用时用 3 步问答生成 | 画像 |

其他调整：
- 侧边栏顶部的"通用模式"下拉框 → 改成「正在为 **小林的生活记录** 创作 ▾」，明确是在给哪个账号做内容
- 侧边栏底部 → 显示**会员卡**：到期日和本月额度，并提供续费入口（对应 M3 的包月模式）
- 设置 → 只保留外观（浅色 / 深色）、存储位置、日志、关于；模型配置整块去掉
- "网关已连接"这类状态平时不显示，只在出错时用中文提示
- **首次使用流程**：激活 → 问 3 个问题（主要做哪个平台 / 什么领域 / 可选粘贴主页链接）→ 自动生成定位 → 首页的选题立即个性化，新用户第一眼看到的不再是一屏的 0

## 3. 视觉方向（三选一）

同一份内容做成三种风格，效果图：`docs/design/方向*.png`，源文件：`docs/design/mocks/`。

### A · 暖橙手帐 —— "有个搭子陪着你做"
- **情绪**：亲切、轻松、不怕做错
- **视觉**：奶油纸色底，logo 的珊瑚橙作主色；按钮和输入框带**实心偏移阴影**（像贴纸），标签微微倾斜；标题下有手绘波浪线；logo 里的两个小幽灵用于空状态、加载、成功提示
- **适合**：新手，尤其是女性和生活方式类创作者（小红书主力人群）
- **风险**：做过头会显得幼稚；专业用户可能觉得不够"工具感"
- **不要做**：满屏插画、每个角落都放吉祥物、彩虹配色

### B · 创作者工作室 —— "我在用专业工具做内容"
- **情绪**：专注、高效、有成就感
- **视觉**：深色界面（也提供浅色），**作品缩略图占主角**，界面本身尽量不抢眼（参考剪映、Figma）；窄图标栏 + 右侧"进行中 / 本周发布"面板；橙色只用于主要操作
- **适合**：有一定经验、产出量大、做视频较多的创作者
- **风险**：新用户还没有作品时，页面会显得空；深色对小白不够亲切
- **不要做**：霓虹光效、玻璃拟态、渐变光斑

### C · 杂志编辑部 —— "每天一场选题会"
- **情绪**：有品位、有条理、像有个主编在帮你
- **视觉**：首页做成报纸头版：「今日选题会 · 第 12 期」，宋体大标题，细线分栏；头条选题附带理由（热度数据 + 和账号的匹配度）；橙色只作点缀
- **适合**：图文、知识类、公众号创作者
- **风险**：中文宋体需要随软件带字体文件（思源宋体子集约 3–5MB）；年轻用户可能觉得严肃；信息密度高
- **不要做**：做成真的报纸（假折痕、泛黄纸）

### 我的建议：**A 为主，吸收 B 的"作品预览优先"**
- A 和 logo 的气质一致，最贴合"小白 + 搭子"的产品定位，而且去掉 logo 也认得出来
- 「创作」页和「我的作品」借用 B 的做法，让生成的卡片和视频成为画面主角。用户花钱买的是作品，作品应该最显眼
- C 的"每个选题附带推荐理由"值得保留，放进 A 的选题卡片里（效果图 A 已经带上了）

## 4. 实施计划

| 阶段 | 内容 | 验证 |
|---|---|---|
| **U0 品牌**（✅ 已完成） | logo、名字、Agent 自称、去掉 Google Fonts | 已在浏览器中核对 |
| **U1 设计系统** | 颜色 / 字号 / 间距 / 圆角 / 阴影的 token（含深色模式），按钮、输入框、卡片、标签、空状态、加载状态这些基础组件，以及吉祥物素材（生成几个姿势：思考、完成、出错、空） | 组件展示页 |
| **U2 框架 + 首页** | 新侧边栏和导航、会员卡、账号切换、首页 | 浏览器截图 + 独立视觉评审（不看代码，只看截图） |
| **U3 创作页** | 对话 + 右侧作品预览 + 模板入口 + 按场景分组的全部能力 | 实际跑一次"小红书图文"全流程 |
| **U4 其余页面** | 找灵感、我的作品、发布、我的定位、首次使用流程、设置 | 逐页截图 |
| **U5 打磨** | 做减法：去掉多余的容器、说明文字和装饰；深色模式；键盘操作；Windows 高分屏（125% / 150% 缩放）；最小窗口 960×640 | 两个平台的真实窗口截图 |

工程约定：
- `src/lib/api.ts` 保持和上游一致，页面组件可以大改。这样上游后端升级时，只需要对接接口变化
- 继续用纯 CSS + CSS 变量，不引入大型 UI 库，保持包体积小
- 字体用系统字体（苹方 / 微软雅黑）；选 C 的话再单独带宋体子集
